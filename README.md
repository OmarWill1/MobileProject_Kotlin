Cette application mobile contient 8 pages principales :  

1. **Accueil (Page1)** – Illustration et bouton pour commencer.  
2. **Login** – Formulaire pour se connecter.  
3. **Sign Up** – Formulaire pour créer un compte.  
4. **Shop** – Affichage des produits avec un produit cliquable.  
5. **ProductDetail** – Détails du produit et ajout au panier.  
6. **Cart** – Gestion du nombre de produits et prix total.  
7. **OrderConfirmation** – Confirmation de commande avec icône de succès.  
8. **OrderError** – Page d’erreur en cas de problème de commande.  

## Fonctionnalités

- Navigation entre les pages via `NavController`.  
- Utilisation d’un itérateur pour afficher les produits (`listOf` + `items`).  
- Variables nullable pour la gestion des commandes.  
- UI réalisée à partir du design Figma fourni.
